# 🐦‍⬛ CrowGram Cloud Storage

**CrowGram** — это открытая децентрализованная система виртуальных дисков, превращающая безлимитное облако Telegram в структурированное персональное хранилище.

[English Version (README.md)](README.md) | [Документация Plugin SDK](https://www.google.com/search?q=PLUGINS_API_RU.md)

---

## ✨ Основные возможности

* 💽 **Виртуальные диски**: Структурирование файлов по буквам дисков (C:, D: и т.д.), привязанным к приватным каналам Telegram.
* ⚡ **Нарезка и стриминг**: Загрузка файлов любого объема с автоматической нарезкой на чанки и мгновенным онлайн-просмотром.
* 🔐 **Защита и восстановление**: Опциональный пароль на вход в веб-интерфейс с мгновенной отправкой бэкапа в *Избранное (Saved Messages)* Telegram.
* 🧩 **Модульная система плагинов**: Расширение функционала через JS-плагины (галереи, аудиоплееры, редакторы кода).
* 🔄 **Облачная синхронизация**: Автоматический бэкап структуры файлов и баз данных в Telegram.

## 🚀 Быстрый старт

### Требования

* Python 3.10+
* Ключи Telegram API ID и API Hash (Получить за 1 минуту на [my.telegram.org](https://my.telegram.org))

### Установка и запуск

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/your-username/CrowGram.git
cd CrowGram

```


2. **Установите зависимости:**
```bash
pip install -r requirements.txt

```


3. **Запустите приложение:**
```bash
python app.py

```


4. **Мастер настройки:**
Интерфейс откроется в браузере автоматически. Пройдите простой 4-шаговый мастер установки.
