CrowGram

    Ваше персональное безлимитное облачное хранилище на базе Telegram.

    Превратите инфраструктуру Telegram в структурированный виртуальный диск с поддержкой нарезки файлов на чанки, шифрованием и кроссплатформенным десктопным интерфейсом.

📖 Язык: 🇬🇧 English | Русский
✨ Основные возможности

    🗂️ Мультидисковая структура — Привязка отдельных Telegram-каналов или «Избранного» к изолированным виртуальным дискам (Диск C:, Диск D:).

    🧩 Умная нарезка на чанки — Загрузка файлов любого размера частями в облако Telegram в обход стандартных ограничений.

    💾 Резервное копирование и восстановление — Мгновенный экспорт/импорт базы метаданных в .json и облачная синхронизация через «Избранное».

    📝 Встроенный текстовый редактор — Просмотр и редактирование .md, .txt и файлов исходного кода прямо в приложении.

    🔌 Система плагинов (CrowAPI) — Создание пользовательских расширений, двухпанельных менеджеров (CrowCommander) и инструментов автоматизации через JS SDK.

    🎨 Темы оформления и локализация — 7 встроенных цветовых тем и полная поддержка русского и английского языков.

    🔒 Конфиденциальность — Никакой сторонней телеметрии. Файлы и база метаданных хранятся только локально и в ваших приватных Telegram-диалогах.

Запуск из исходного кода

Требования: Python 3.10+

git clone https://github.com/yourusername/CrowGram.git

cd CrowGram

pip install -r requirements.txt

python run_desktop.py
🛠️ Первый запуск

    Запустите CrowGram и пройдите по шагам Мастера настройки.

    Укажите ваши Telegram API ID и API Hash (получить можно на my.telegram.org).

    Введите номер телефона, подтвердите код из Telegram (поддерживается двухфакторный 2FA-пароль).

    Создайте свой первый диск или нажмите «Восстановить из Telegram» для мгновенной подтяжки существующей базы.
