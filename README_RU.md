# 🐦‍⬛ CrowGram Cloud Storage

**CrowGram** — это открытая децентрализованная система виртуальных дисков, превращающая безлимитное облако Telegram в структурированное персональное медиа-хранилище высокой производительности.

[English Version (README.md)](README.md)

---

## ✨ Основные возможности

* 💽 **Виртуальные диски**: Структурирование файлов по буквам дисков (C:, D: и т.д.), привязанным к приватным каналам Telegram.
* ⚡ **Нарезка и стриминг**: Нарезка файлов на чанки с многопоточной загрузкой и мгновенным онлайн-просмотром видео и аудио без ожидания скачивания.
* 🖥️ **Кроссплатформенное приложение**: Нативный графический клиент на базе `pywebview` с гладким воспроизведением MKV/MP4/FLAC, поддержкой субтитров и системных декодеров.
* ⚔️ **CrowCommander**: Встроенный двухпанельный файловый менеджер для удобного обмена файлами между ПК и облаком Telegram.
* 🔐 **Защита и восстановление**: Опциональный пароль на вход в веб-интерфейс с мгновенным бэкапом базы данных и ключей в *Избранное (Saved Messages)* Telegram.
* 🧩 **Модульная система плагинов**: Расширение функционала через JS-плагины (кастомные плееры, просмотрщики файлов и редакции кода).

## 🚀 Быстрый старт

### Требования

* Python 3.10+
* Ключи Telegram API ID и API Hash (Получить за 1 минуту на [my.telegram.org](https://my.telegram.org))

### Локальный запуск (Desktop Mode)

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/SlowCrow666/CrowGram.git
cd CrowGram

```


2. **Установите зависимости:**
```bash
pip install -r requirements.txt

```


3. **Запустите приложение:**
* **Windows**: Двойной клик по `run.bat` или в консоли:
```bash
python desktop_app.py

```


* **Linux**:
```bash
./run.sh

```


* **macOS**:
```bash
./run_mac.command

```

## 🛠️ Технологический стек

* **Backend**: Python 3.11, FastAPI, Uvicorn, Pyrogram, SQLite.
* **Frontend**: HTML5, Modern CSS Variables, Vanilla JS, ArtPlayer.
* **Desktop Shell**: PyWebView.
* **CI/CD**: GitHub Actions (Автосборка релизов под Windows, Linux, macOS).
