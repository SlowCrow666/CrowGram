
# CrowGram

### Персональное безлимитное облачное хранилище на базе Telegram

  🇬🇧 English Version •  Обзор •  Возможности •  Быстрый старт •  Плагины




[](LICENSE)

  Превратите Telegram в удобный виртуальный диск: файловая структура, нарезка на чанки, синхронизация метаданных и нативное десктопное приложение.



---

## ⚡ Зачем нужен CrowGram?

Telegram предоставляет практически неограниченное облако для файлов, но в нём нет структуры папок, дисков и привычного проводника. **CrowGram решает эту задачу.**

```
┌─────────────────────────────────────────────────────────────┐
│                       Ядро CrowGram                         │
│     [Диски и Папки] ⇄ [Потоковый чанкер] ⇄ [База SQLite]    │
└──────────────┬───────────────────────────────┬──────────────┘
               │                               │
       ┌───────▼────────┐             ┌────────▼────────┐
       │   Избранное    │             │ Приватный канал │
       │ (Синхронизация)│             │ (Хранилище чанков)│
       └────────────────┘             └─────────────────┘
```

---

## 🌟 Преимущества


  
    
      🗂️ Мультидисковая структура
      Привязывайте каналы или «Избранное» к изолированным буквам дисков (Диск C:, Диск D:) с индивидуальными настройками.
    
    
      🧩 Прозрачный чанкинг
      Загружайте файлы любого размера — система автоматически делит их на зашифрованные части и собирает обратно при скачивании.
    
  
  
    
      🔄 Облачная синхронизация
      Создание и восстановление бэкапа базы метаданных через Telegram в один клик. Переезжайте на новый ПК без потери структуры.
    
    
      📝 Встроенный редактор
      Полноценная работа с текстовыми файлами, кодом и Markdown с предпросмотром и подсветкой синтаксиса прямо в интерфейсе.
    
  
  
    
      🔌 Расширения CrowAPI
      Поддержка пользовательских плагинов: двухпанельный проводник (CrowCommander), пакетная обработка и автоматизация.
    
    
      🎨 Темы и безопасность
      7 цветовых схем оформления, полная поддержка 2FA-паролей Telegram и работа без сторонних промежуточных серверов.

### 🛠️ Вариант 2: Запуск из исходников

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/yourusername/CrowGram.git
   cd CrowGram
   ```

2. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите приложение**
   ```bash
   python run_desktop.py
   ```

---

## 🧭 Первый запуск

1. **Данные Telegram API:** В мастере настройки укажите `api_id` и `api_hash` с my.telegram.org.
2. **Вход:** Введите номер телефона и код подтверждения (облачные пароли 2FA поддерживаются).
3. **Выбор диска или Восстановление:**
   * Создайте новый диск для хранения, **ИЛИ**
   * На шаге 4 нажмите **«Восстановить из Telegram»** для мгновенной загрузки уже существующей базы.

## 🔌 Система плагинов

CrowGram предоставляет глобальный JS SDK через объект `window.CrowAPI`:

```javascript
CrowAPI.registerPlugin({
  id: 'quick-stats',
  name: 'Статистика диска',
  init() {
    CrowAPI.addToolbarButton({
      icon: '📊',
      title: 'Статистика',
      onClick: () => CrowAPI.showModal('Всего дисков: ' + CrowAPI.getDrives().length)
    });
  }
});
```

## 🛡️ Безопасность и приватность

* **Без телеметрии:** Никаких логов на сторонние серверы или аналитики.
* **Прямое соединение:** Все запросы идут исключительно между вашим ПК и официальными серверами Telegram MTProto.
